# Global assistant search

Global search is fully deterministic. `POST /api/v1/search/assistant` classifies the query, retrieves allow-listed public product fields, and generates its message and follow-up with the rule engine. No AI model is called. Prices, inventory, images and product IDs always come from the catalog query.

Required server-only variables:

```env
# No AI configuration is required for assistant search.
```

RAG is intentionally not required for current catalog search. Add a retriever only for long, curated public policy/specification documents. Never index customer data or use RAG as the source of current price/stock.

Fallback behavior: catalog/query failures return the existing HTTP 503 response; successful responses are always generated by rules.
